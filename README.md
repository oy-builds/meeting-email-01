# The Meeting That Should Have Been an Email

One line, at most 200 characters, that makes a meeting-that-should-have-been-an-email funny. Twelve people, no agenda, one decision worth a single sentence — and the sentence they chose was to circle back next week.

`main.ts` (Node 22+) writes the line to `/output/entry.txt`. Run it with `node main.ts`.
